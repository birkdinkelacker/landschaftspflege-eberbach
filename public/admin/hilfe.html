Texte und Fotos ändern

Mit Ihrem persönlichen Zugang können Sie die Inhalte Ihrer Webseite selbst bearbeiten. Für die erste Anmeldung benötigen Sie eine Einladung an Ihre E-Mail-Adresse.

CMS öffnen ↗

Einen Text bearbeiten

  1. Öffnen Sie den passenden Bereich, zum Beispiel Startseite, Über uns oder Kontakt und Adresse.
  2. Ändern Sie den Text im gewünschten Feld. Eine Leerzeile trennt zwei Absätze.
  3. Klicken Sie auf Save. Warten Sie, bis das Speichern bestätigt wurde.
  4. Die Webseite wird danach neu veröffentlicht. Warten Sie einige Minuten und laden Sie die öffentliche Webseite neu.

Ein Foto ersetzen

  1. Öffnen Sie den gewünschten Bereich und das Bildfeld.
  2. Wählen Sie ein vorhandenes Foto aus oder laden Sie ein neues hoch.
  3. Ergänzen Sie eine kurze Bildbeschreibung, zum Beispiel „Geschnittene Hecke im Garten“.
  4. Speichern Sie den gesamten Bereich mit Save. Ein Upload allein ändert noch kein Bild auf der Webseite.

Verwenden Sie bei jeder Leistung ein eigenes Foto. Wenn kein passendes Bild vorliegt, lassen Sie das Bildfeld leer: Dann erscheint „Foto folgt“. Aktuell gibt es diesen Platzhalter bei Obstbaumpflege und Facility Management.

Verwenden Sie möglichst JPG, PNG oder WebP unter 1 MB. Fotos, die noch auf der Webseite verwendet werden, bitte nicht aus der Mediathek löschen.

Leistungen oder Galeriebilder ergänzen

Öffnen Sie Leistungen oder Bildergalerie. Klappen Sie einen bestehenden Eintrag zum Bearbeiten auf oder ergänzen Sie einen Eintrag über Add an item. Die Einträge können Sie auch umsortieren. Speichern Sie anschließend den Bereich.

In der Bildergalerie ist ein Foto erforderlich. Bei den Leistungen können Sie stattdessen einen Platzhalter lassen.

Was Sie ändern können

  • Unternehmensangaben, Überschriften und Texte
  • Fotos und Bildbeschreibungen
  • Leistungen und Bildergalerie
  • Telefonnummer, E-Mail-Adresse und Anschrift
  • Die hinterlegten Abschnitte für Impressum und Datenschutz

Die rechtlichen Texte müssen vor einer Veröffentlichung vollständig und geprüft sein. Das CMS erstellt keine rechtssicheren Texte.

Wenn etwas nicht klappt

  • Kein Zugriff: Melden Sie sich mit genau der eingeladenen E-Mail-Adresse an. Bei einem Kontowechsel zuerst abmelden.
  • Keine Anmelde-E-Mail: Prüfen Sie den Spam-Ordner und die Schreibweise Ihrer Adresse.
  • Die Änderung fehlt: Prüfen Sie, ob der gesamte Bereich gespeichert wurde. Warten Sie die Veröffentlichung ab und laden Sie die Webseite neu.
  • Die Änderung erscheint auch später nicht: Wenden Sie sich an Ihren Ansprechpartner. Bei einer fehlgeschlagenen Veröffentlichung bleibt die bisherige Webseite online.
