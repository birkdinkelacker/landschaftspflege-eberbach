Texte und Bilder bearbeiten

Die Inhalte dieser Webseite werden mit Pages CMS verwaltet.

CMS öffnen
  1. Mit deinem GitHub-Konto anmelden. Beim ersten Mal Pages CMS für das Repository birkdinkelacker/landschaftspflege-eberbach freigeben. Wähle nur dieses Repository aus.
  2. Das Repository und den Branch main öffnen. Dann den gewünschten Bereich auswählen, zum Beispiel „Über uns“, „Leistungen“ oder „Bildergalerie“.
  3. Text ändern oder ein Bild hochladen und auswählen. Danach speichern.

Speichern schreibt die Änderungen nach GitHub. Wenn Netlify mit diesem Repository und dem Branch main verbunden ist, wird die Webseite danach automatisch neu gebaut. Das kann ein paar Minuten dauern. CMS und Veröffentlichung sind zwei getrennte Schritte.

Ein hochgeladenes Foto erscheint erst auf der Webseite, wenn du es auch in einem Inhaltsbereich auswählst und diesen speicherst.
